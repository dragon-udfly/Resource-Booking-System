# Hall Schedule: User Guide

## Introduction
The **Hall Schedule** page provides a real-time calendar and list view of all upcoming events in the District Secretariat halls. It allows the public and officers to check hall availability before making a booking.

**URL:** `/hallschedule` (or via "Halls" link on Homepage)

---

## Features

### 1. Upcoming Events List
On the left side, a scrollable list displays details of future bookings:
*   **Programme Name:** The title of the event.
    *   *Note:* Emergency bookings are highlighted with yellow text.
*   **Hall Type:** Which hall is booked.
*   **Applicant:** Who reserved the hall.
*   **Date & Time:** Event duration.
*   **Status:**
    *   **Approved (Green):** Confirmed booking.
    *   **Pending (Blue):** Awaiting approval (Hall is tentatively blocked).
    *   **Rejected (Red):** Booking denied (Slot is free).

### 2. Live Calendar
The interactive calendar visualizes hall occupancy for the entire month:
*   **Green Dates:** Confirmed (Approved) bookings exist on this day.
*   **Blue Dates:** Pending bookings exist on this day.
*   **White Dates:** completely free.
*   **Today:** Highlighted with a blue circle.

### 3. Navigation Buttons
Top-left buttons provide quick access:
*   **Home:** Return to the landing page.
*   **Halls:** View a detailed description of all halls.
*   **Book Hall:** Proceed to the booking application form.
