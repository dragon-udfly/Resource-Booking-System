# Halls Overview: பயனர் வழிகாட்டி

## அறிமுகம்
**Halls Overview** பக்கமானது செயலகத்தில் உள்ள அனைத்து வசதிகளின் பட்டியலாக செயல்படுகிறது. இது ஒவ்வொரு மண்டபத்தின் பண்புகள் மற்றும் தற்போதைய செயல்பாட்டு நிலை பற்றிய அத்தியாவசிய தகவல்களை வழங்குகிறது.

**URL:** `/halls/overview`

---

## பக்கத்தை அணுகுதல் (Accessing the Page)
*   **Hall Schedule** பக்கத்திலிருந்து, **"Halls"** பொத்தானைக் கிளிக் செய்யவும்.
*   **Homepage** விருந்து, "Halls" என்று அடையாளம் காணும் உள்ளடக்கத்தை கிளிக் செய்யவும்.

## காட்டப்படும் தகவல்கள் (Information Displayed)
அட்டவணை ஒவ்வொரு வசதியின் வரிசை வாரியான முறிவை அளிக்கிறது:

### 1. Hall Type
மண்டபத்தின் குறிப்பிட்ட பெயர் அல்லது வகை (எ.கா., "Main Conference Hall", "Mini Auditorium").

### 2. Description
மண்டபத்தின் நோக்கம் மற்றும் வசதிகள் பற்றிய சுருக்கமான தொகுப்பு.

### 3. Current State
முன்பதிவு செய்ய மண்டபம் தயாராக உள்ளதா என்பதைக் குறிக்கிறது:
*   **Available:** உடனடி முன்பதிவுக்கு தயார்.
*   **Unavailable/Maintenance:** தற்போது சேவையில் இல்லை (**சிவப்பு** நிறத்தில் உரை முன்னிலைப்படுத்தப்பட்டுள்ளது).

### 4. Special Notice
குறிப்பிட்ட மண்டபம் தொடர்பான ஏதேனும் முக்கியமான விழிப்பூட்டல்கள் (எ.கா., "AC under repair", "Projector unavailable").
