# Audit Log Module: பயனர் வழிகாட்டி

## அறிமுகம்
**Audit Log** ஆனது கணினியில் செய்யப்படும் முக்கிய செயல்களைக் கண்காணிப்பதன் மூலம் பொறுப்புக்கூறலை உறுதி செய்கிறது. இது யார் என்ன செய்தார்கள் மற்றும் எப்போது செய்தார்கள் என்பதற்கான வெளிப்படையான பதிவை வழங்குகிறது.

**அணுகல் கட்டுப்பாடு:** இந்தப் பக்கத்திற்கு `view_audit_log` அனுமதி தேவை.

---

## மொடியூலை அணுகுதல்
1.  கணினியில் **Log in** செய்யவும்.
2.  பிரதான வழிசெலுத்தல் மெனுவில் **Audit Log** என்பதை கிளிக் செய்யவும்.

---

## அம்சங்கள்

### Audit Records Table
கணினி நிகழ்வுகளை காலவரிசைப்படி பதிவு செய்கிறது. அட்டவணை பின்வருவனவற்றைக் காட்டுகிறது:

*   **Log Title:** நிகழ்வின் விளக்கம் (எ.கா., *"User X logged in"*, *"Booking Y approved"*).
*   **Performed By:** செயலை செய்த நபரின் பயனர் ஐடி அல்லது பெயர்.
*   **Date Performed:** நிகழ்வின் தேதி (YYYY-MM-DD).
*   **Time Performed:** நிகழ்வின் நேரம் (HH:MM:SS).
