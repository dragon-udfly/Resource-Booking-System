# Halls Module: பயனர் வழிகாட்டி

## அறிமுகம்
**Halls** மொடியூல் பயனர்களை செயலகத்தில் கிடைக்கும் மண்டபங்களைப் பற்றிய விவரங்களைப் பார்க்க அனுமதிக்கிறது. நிகழ்வுகளைத் திட்டமிடுவதற்கும் முன்பதிவு செய்வதற்கு முன் திறனைச் சரிபார்க்கவும் இது உதவுகிறது.

**அணுகல் கட்டுப்பாடு:** இந்தப் பக்கத்திற்கு `view_halls` அனுமதி தேவை.

---

## மொடியூலை அணுகுதல்
1.  கணினியில் **Log in** செய்யவும்.
2.  பிரதான வழிசெலுத்தல் மெனுவில் **Halls** என்பதை கிளிக் செய்யவும்.

---

## அம்சங்கள்

### Halls List
மொடியூல் பின்வரும் விவரங்களுடன் மண்டபங்களின் விரிவான பட்டியலை அளிக்கிறது:

*   **Hall ID:** மண்டபத்திற்கான தனிப்பட்ட அடையாளம்.
*   **Hall Type:** மண்டபத்தின் வகை (எ.கா., Conference Hall, Meeting Room).
*   **Capacity:** அனுமதிக்கப்பட்ட அதிகபட்ச நபர்களின் எண்ணிக்கை.
*   **Description:** மண்டபத்தின் அம்சங்களின் சுருக்கமான கண்ணோட்டம்.
*   **Hall Status:** தற்போதைய செயல்பாட்டு நிலை (எ.கா., Available, Maintenance).
*   **Special Notice:** மண்டபம் தொடர்பான ஏதேனும் முக்கியமான விழிப்பூட்டல்கள் அல்லது நிபந்தனைகள்.
