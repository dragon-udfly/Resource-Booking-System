# Login System: பயனர் வழிகாட்டி & செயல்முறை அறிக்கை

## அறிமுகம்
இந்த ஆவணம் Resource Booking System-க்கான **Login Process**-ஐ கோடிட்டுக் காட்டுகிறது. அங்கீகாரம், சரிபார்ப்பு விதிகள் மற்றும் பயனர் பாத்திரங்களின் அடிப்படையில் வழிமாற்று தர்க்கம் ஆகியவற்றை இது விவரிக்கிறது.

---

## 2. உள்நுழைவு பக்கத்தை அணுகுதல் (Accessing the Login Page)
**URL:** `/login`

1.  **Navigation:**
    *   முகப்புப் பக்க வழிசெலுத்தல் பட்டியில் உள்ள "Log In" இணைப்பு வழியாக பயனர்கள் உள்நுழைவுப் பக்கத்தை அணுகலாம்.
    *   URL வழியாக நேரடி அணுகல்.
2.  **Interface:**
    *   முந்தைய பக்கத்திற்குத் திரும்ப "Back" பொத்தானைக் கொண்ட சுத்தமான இடைமுகத்தைக் கொண்டுள்ளது.
    *   **NIC** மற்றும் **Passcode** க்கான உள்ளீட்டு புலங்கள்.

## 2. சான்றுகள் & சமர்ப்பிப்பு (Credentials & Submission)
**Form Fields:**

1.  **NIC (National Identity Card) Number:**
    *   *வகை:* உரை (Text)
    *   *தேவை:* ஆம்
    *   *விளக்கம்:* அதிகாரிக்கான தனிப்பட்ட அடையாளம்.
2.  **Password:**
    *   *வகை:* கடவுச்சொல் (Password)
    *   *தேவை:* ஆம்
    *   *விளக்கம்:* பயனர் கணக்குடன் தொடர்புடைய பாதுகாப்பான கடவுச்சொல்.

**Client-Side Validation:**
*   ஒரு ஜாவாஸ்கிரிப்ட் ஸ்கிரிப்ட் உள்ளீட்டு புலங்களைக் கண்காணிக்கிறது.
*   **Login** பொத்தான் முன்னிருப்பாக **முடக்கப்பட்டுள்ளது** (disabled), NIC மற்றும் Password புலங்கள் இரண்டிலும் உரை இருந்தால் மட்டுமே **இயக்கப்படும்** (enabled).
*   இயக்கப்படும் போது பொத்தானின் காட்சி மாறுகிறது (அடர் நீலம்).

## 3. வழிமாற்று & அணுகல் கட்டுப்பாடு (Redirection & Access Control)
பயனர்களுக்கு ஒதுக்கப்பட்ட **Role**-இன் அடிப்படையில் கணினி அவர்களை வழிநடத்துகிறது:

*   **Admin Role:**
    *   **Admin Dashboard** (`/admin`)-க்கு வழிநடத்தப்படும்.
*   **User/Officer Role:**
    *   **User Dashboard** (`/dashboard`)-க்கு வழிநடத்தப்படும்.

## 4. பிழை கையாளுதல் (Error Handling)
அங்கீகாரம் தோல்வியுற்றால் (தவறான NIC அல்லது தவறான கடவுச்சொல்):
*    பயனர் மீண்டும் உள்நுழைவுப் பக்கத்திற்குத் திருப்பி அனுப்பப்படுவார்.
*   ஒரு பிழை செய்தி காட்டப்படும்: *"The provided credentials do not match our records."*
*   வசதிக்காக முன்பு உள்ளிட்ட மதிப்பை NIC புலம் தக்க வைத்துக் கொள்கிறது.

## சுருக்க அணி

| அம்சம் | விவரங்கள் |
| :--- | :--- |
| **முதன்மை விசை** | NIC Number |
| **பாதுகாப்பு** | Hashed Passcode சரிபார்ப்பு |
| **பாத்திர கையாளுதல்** | தானியங்கி வழிமாற்று (Admin vs. User) |
| **பாதுகாப்பு பதிவு** | தானியங்கி Audit Log பதிவு |
| **பிழை கருத்து** | நிலையான தவறான சான்றுகள் செய்தி |
