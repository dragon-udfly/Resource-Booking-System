# User Dashboard & Navigation: பயனர் வழிகாட்டி

## அறிமுகம்
**Dashboard** என்பது Resource Booking System-ன் மையக் கட்டுப்பாட்டு மையமாகும். அதன் தளவமைப்பு மற்றும் உள்ளடக்கம் உங்களுக்கு ஒதுக்கப்பட்ட **Permissions**-ஐப் பொறுத்தது.

*   **நிர்வாக மற்றும் மேற்பார்வை பாத்திரங்கள்:** (GA, AGA, AO, Requester) அனைத்து நிலுவையில் உள்ள கணினி விண்ணப்பங்களின் விரிவான வரிசையைக் காணலாம்.
*   **நிலையான பயனர்கள்:** அணுகல் உரிமைகளைப் பொறுத்து எளிமைப்படுத்தப்பட்ட அல்லது வெற்று இடைமுகத்தைக் காணலாம்.

---

## 1. Navigation Bar
விரைவான அணுகலுக்காக ஒவ்வொரு பக்கத்திலும் மேல் வழிசெலுத்தல் பட்டி தோன்றும்.

### முக்கிய இணைப்புகள்
*   **Preference:** தனிப்பட்ட கணக்கு அமைப்புகளை நிர்வகிக்கவும் (Email, Contact, Password).
*   **Dashboard:** இந்த பிரதான பார்வைக்குத் திரும்பும்.
*   **Officers:** (Permission: `view_officers`) பதிவுசெய்யப்பட்ட அதிகாரிகளின் அடைவு.
*   **Halls:** (Permission: `view_halls`) மண்டப காலண்டர் மற்றும் முன்பதிவு விவரங்கள்.
*   **Quarters:** (Permission: `view_quarters`) குடியிருப்பு கிடைக்கும் தன்மை மற்றும் விவரங்கள்.
*   **History:** (Permission: `form_history`) செயலாக்கப்பட்ட விண்ணப்பங்களின் காப்பகம் (Approved/rejected).
*   **Audit Log:** (Permission: `view_audit_log`) கணினி செயல்பாடு பதிவுகள்.

### கணக்கு கட்டுப்பாடுகள் (வலது பக்கம்)
*   **User Info:** உங்கள் தரம்/பதவி மற்றும் பெயரைக் காட்டுகிறது.
*   **Log Out:** உங்கள் அமர்வை பாதுகாப்பாக முடிக்கும்.

## 2. Pending Approvals Dashboard
**பார்வையாளர்கள்:** `GA Approval`, `AGA Approval`, `AO Approval` அல்லது `Requester` அனுமதி உள்ள பயனர்கள்.

இந்த டேஷ்போர்டு ஒரு **Work Queue** ஆக செயல்படுகிறது, இது கணினியில் தற்போது நடவடிக்கைக்காக காத்திருக்கும் அனைத்து விண்ணப்பங்களையும் காட்டுகிறது.

### A. Layout & Tools
*   **Fixed Side Menu:** வலதுபுறத்தில் உள்ள மிதக்கும் மெனு பிரிவுகளுக்கு இடையில் விரைவாக உருட்ட அனுமதிக்கிறது (Hall, Family, Scheduled).
*   **Banner:** "Pending Booking Approvals" என்பதைக் காட்டுகிறது.

### B. Hall Booking Applications
*   **உள்ளடக்கம்:** `Pending` நிலையில் உள்ள அனைத்து மண்டப முன்பதிவுகள்.
*   **நெடுவரிசைகள்:** Applicant Name, Submitted Date, Approval Status (AO/AGA/GA).
*   **செயல்கள்:**
    *   **Review:** முழு விவரங்களையும் பார்க்க மற்றும் ஒப்புதல்/நிராகரிப்பு செய்ய கிளிக் செய்யவும்.
    *   **Emergency:** **மஞ்சள்** நிறத்தில் முன்னிலைப்படுத்தப்பட்ட வரிசைகள் அவசர கோரிக்கைகளைக் குறிக்கின்றன.

### C. Family Quarter Applications
*   **உள்ளடக்கம்:** ஒதுக்கீட்டிற்காக காத்திருக்கும் குடும்ப குடியிருப்பு கோரிக்கைகள்.
*   **வரிசைப்படுத்துதல்:** **Total Marks** மூலம் தானாகவே வரிசைப்படுத்தப்படுகிறது (அதிக முன்னுரிமை மேலே).
*   **நெடுவரிசைகள்:**
    *   **Applicant:** பெயர், தரம், பதவி.
    *   **Total Mark:** மூப்பு/அளவுகோல்களின் அடிப்படையில் கணக்கிடப்பட்ட மதிப்பெண்.
    *   **Verifications:** AO மற்றும் AGA படிகளுக்கான நிலை தூண்டுதல்கள்.
*   **செயல்கள்:** ஆவணங்களைச் சரிபார்க்க அல்லது ஒதுக்கீட்டை அங்கீகரிக்க **Review** என்பதைக் கிளிக் செய்யவும்.

### D. Scheduled Quarter Applications
*   **உள்ளடக்கம்:** ஒதுக்கீட்டிற்காக காத்திருக்கும் திட்டமிடப்பட்ட குடியிருப்பு கோரிக்கைகள்.
*   **நெடுவரிசைகள்:** விண்ணப்பதாரர் விவரங்கள் மற்றும் சரிபார்ப்பு நிலை சங்கிலி.
*   **செயல்கள்:** விண்ணப்பத்தைச் செயல்படுத்த **Review** என்பதைக் கிளிக் செய்யவும்.

## 3. Standard User Dashboard
**பார்வையாளர்கள்:** ஒப்புதல்/கோருபவர் அனுமதிகள் இல்லாத பயனர்கள்.

*   நிலையான பயனர்கள் குறிப்பிட்ட படிவங்களை அணுக **Navigation Bar**-ஐப் பயன்படுத்துவார்கள் (எ.கா., "Halls" -> "Book Hall").
*   பிரதான டேஷ்போர்டு பகுதி காலியாக இருக்கலாம், ஏனெனில் அவர்களின் முதன்மை தொடர்புகள் மைய ஒப்புதல் வரிசையை விட குறிப்பிட்ட செயல்பாட்டு பக்கங்கள் (Halls/Quarters) வழியாக நிகழ்கின்றன.
