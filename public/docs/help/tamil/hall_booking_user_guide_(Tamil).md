# Hall Booking System: பயனர் வழிகாட்டி & செயல்முறை அறிக்கை

## அறிமுகம்
இந்த வழிகாட்டி மண்டப முன்பதிவு பயன்பாட்டு சுழற்சியின் முழுமையான கண்ணோட்டத்தை வழங்குகிறது, இதில் சமர்ப்பித்தல் (Submission), ஒப்புதல் (Approval), ரத்து செய்தல் (Cancellation) மற்றும் வரலாற்று மேலாண்மை (History Management) ஆகியவை அடங்கும். பயனர்கள், Administrative Officers (AO), Additional Government Agents (AGA) மற்றும் Government Agents (GA) ஆகியோர் தங்கள் குறிப்பிட்ட பாத்திரங்கள் மற்றும் திறன்களைப் புரிந்துகொள்ள உதவும் வகையில் இது வடிவமைக்கப்பட்டுள்ளது.

---

## 1. பயன்பாட்டு சமர்ப்பிப்பு (Application Submission)
**பங்கு:** தனிப்பட்ட உதவியாளர் (விண்ணப்பதாரர்) அல்லது பொது பயனர்

1.  **Access:** **Homepage** இருந்து, **Book Hall** பொத்தானைக் கிளிக் செய்யவும்.
2.  **Schedule View:** கிடைக்கும்தன்மையைச் சரிபார்க்க நீங்கள் *Hall Schedule* பக்கத்திற்கு அழைத்துச் செல்லப்படுவீர்கள்.
3.  **Initiate:** மேல் மெனுவில் உள்ள நீல நிற **Book Hall** பொத்தானைக் கிளிக் செய்யவும்.
4.  **Form:** பின்வரும் விவரங்களுடன் "Hall Booking Form"-ஐ நிரப்பவும்:
    *   **Applicant Details:** பெயர், மின்னஞ்சல், வகை (உள்/வெளி).
    *   **Hall Details:** மண்டப வகை, நிகழ்ச்சி/நிகழ்வு பெயர்.
    *   **Schedule:** தேதி, நேரம், கால அளவு.
    *   **Participants:** நபர்களின் எண்ணிக்கை.
    *   **Payment:** கட்டண நிலை, அவசர முன்பதிவு.
    *   **Officer Info:** NIC, தொலைபேசி.
    *   **Confirmation:** "I filled this form..." பெட்டியை சரிபார்க்கவும்.
5.  **Submit:** **Submit for Approval** என்பதைக் கிளிக் செய்யவும்.
6.  **Confirmation:** படிவப் பக்கத்தில் பச்சை நிற "Success" செய்தியைக் காண்பீர்கள்.
7.  **Review:**
    *   கணினியில் உள்நுழையவும்.
    *   உங்கள் **Dashboard**-க்கு செல்லவும்.
    *   **"Submitted Forms"** பகுதியைக் கண்டறியவும்.
    *   உங்கள் முன்பதிவு AO, AGA மற்றும் GA ஆகியவற்றுக்கான நிலை நெடுவரிசைகளுடன் **Hall Booking Applications** அட்டவணையில் தோன்றும்.

## 2. ஒப்புதல் பணிப்பாய்வு (Approval Workflow)
விண்ணப்பம் ஒப்புதல்களின் கண்டிப்பான படிநிலையை கடந்து செல்ல வேண்டும்.

### படி 1: Administrative Officer (AO)
*   **செயல்:** முழுமை மற்றும் கிடைக்கும்தன்மைக்காக விண்ணப்பத்தை மதிப்பாய்வு செய்கிறார்.
*   **முடிவு:**
    *   **Approve:** "Yes" என்பதைத் தேர்ந்தெடுத்து Submit செய்யவும். விண்ணப்பம் AGA-வுக்கு நகர்கிறது.
    *   **Reject:** "No" என்பதைத் தேர்ந்தெடுத்து Submit செய்யவும். விண்ணப்ப நிலை **Rejected** ஆகிறது.

### படி 2: Additional Government Agent (AGA)
*   **செயல்:** AO-வின் பரிந்துரையை சரிபார்க்கிறார்.
*   **முடிவு:**
    *   **Approve:** "Yes" என்பதைத் தேர்ந்தெடுத்து Submit செய்யவும். விண்ணப்பம் GA-வுக்கு நகர்கிறது.
    *   **Reject:** "No" என்பதைத் தேர்ந்தெடுத்து Submit செய்யவும். நிலை **Rejected** ஆகிறது.

### படி 3: Government Agent (GA) - இறுதி அதிகாரம்
*   **செயல்:** இறுதி ஒப்புதலை வழங்குகிறார்.
*   **முடிவு:**
    *   **Approve:** "Yes" -> **Finalize** என்பதைத் தேர்ந்தெடுக்கவும். நிலை **Approved** ஆகிறது.
    *   **Reject:** "No" -> **Enter Reason** -> **Finalize** என்பதைத் தேர்ந்தெடுக்கவும். நிலை **Rejected** ஆகிறது.

## 3. ஒதுக்கீட்டிற்குப் பிந்தைய மேலாண்மை (Post-Approval Management)
விண்ணப்பம் செயலில் இருந்தால் (எதிர்கால நிகழ்வு), குறிப்பிட்ட விதிகளின் கீழ் அதை ரத்து செய்யலாம்.

### Scenario A: கோருபவர் ரத்து செய்ய விரும்புகிறார்
*   **நிபந்தனை:** விண்ணப்பம் **100% Pending** ஆக இருக்க வேண்டும் (எந்த அதிகாரியும் அதைத் தொடவில்லை).
*   **செயல்:** Dashboard -> "Review" கிளிக் செய்யவும் -> "Cancel Booking" கிளிக் செய்யவும்.
*   **முடிவு:** முன்பதிவு ரத்து செய்யப்பட்டது.
*   **கட்டுப்பாடு:** AO/AGA ஏற்கனவே ஒப்புதல் அளித்திருந்தால், கோருபவர் ரத்து செய்ய **முடியாது**. அவர்கள் GA-ஐ தொடர்பு கொள்ள வேண்டும்.

### Scenario B: Government Agent (GA) ரத்து செய்ய விரும்புகிறார்
*   **நிபந்தனை:** விண்ணப்பம் **Approved** ஆனால் நிகழ்வு இன்னும் நடக்கவில்லை (எ.கா., அவசர ரத்து).
*   **செயல்:**
    1.  **History**-க்கு செல்லவும்.
    2.  Approved Booking-ல் **View** கிளிக் செய்யவும்.
    3.  **Cancel Booking** கிளிக் செய்யவும்.
    4.  **Reason** உள்ளிடவும் (தேவை).
    5.  உறுதிப்படுத்தவும்.
*   **முடிவு:** நிலை **Cancelled** ஆக மாறுகிறது.

## சிறப்பு அம்சம்: அவசர முன்பதிவு (Emergency Booking)
கோருபவர்கள் விண்ணப்பத்தை **Emergency** என்று கொடியிடலாம்.

*   **எப்படி கொடியிடுவது:** முன்பதிவு படிவத்தில் "Emergency Booking" என்பதற்கு **"Yes"** என்பதைத் தேர்ந்தெடுக்கவும்.
*   **விளைவு:**
    *   அதிகாரி டாஷ்போர்டில் விண்ணப்ப வரிசை **மஞ்சள் நிறத்தில் முன்னிலைப்படுத்தப்பட்டுள்ளது**.
    *   பொது அட்டவணையில் நிரல் பெயருக்குப் பிறகு **"(Emergency Booking)"** என்ற உரை சேர்க்கப்படுகிறது.
*   **ஒப்புதல்:**
    *   இது **நிலையான ஒப்புதல் பணிப்பாய்வை** (AO -> AGA -> GA) பின்பற்றுகிறது.
    *   முன்னிலைப்படுத்தல் அதிகாரிகள் மதிப்பாய்வுக்கு முன்னுரிமை அளிக்க ஒரு காட்சி குறிப்பாக செயல்படுகிறது.
    *   **குறிப்பு:** ஒரு கோரிக்கை அவசரநிலைக்குத் தகுதியானதா என்பதைத் தீர்மானிப்பது ஒப்புதல் அளிக்கும் அதிகாரிகளின் பொறுப்பாகும்.

## 4. வரலாறு & காப்பகப்படுத்தல் (History & Archival)
தணிக்கை நோக்கங்களுக்காக பதிவுகள் வைக்கப்படுகின்றன. **Deletion** (நிரந்தர நீக்கம்) குறிப்பிட்ட துப்புரவு காட்சிகளுக்கு மட்டுமே.

### விதி 1: History Cleanup (கடந்த நிகழ்வுகள்)
*   **யார்:** எந்த பயனரும் (உரிமையாளர்/ஒப்புதல் அளிப்பவர்).
*   **நிபந்தனை:** நிகழ்வு தேதி **கடந்துவிட்டது** (நேற்று அல்லது முன்னதாக).
*   **செயல்:**
    1.  **History**-க்கு செல்லவும்.
    2.  **View** கிளிக் செய்யவும்.
    3.  **Delete Record** கிளிக் செய்யவும்.
    4.  மாதிரியில் உறுதிப்படுத்தவும்.
*   **முடிவு:** பதிவு தரவுத்தளத்திலிருந்து நிரந்தரமாக அகற்றப்படுகிறது.

### விதி 2: Administrative Cleanup (நிராகரிக்கப்பட்ட விண்ணப்பங்கள்)
*   **யார்:** Administrative Officer (AO) மட்டும்.
*   **நிபந்தனை:**
    1.  விண்ணப்பம் **Rejected** (இறுதி நிலை அமைக்கப்பட்டுள்ளது).
    2.  GA இன்னும் அதைச் செயல்படுத்தவில்லை (GA நிலை நிலுவையில் உள்ளது).
*   **செயல்:** History -> View -> Delete Record.
*   **முடிவு:** கணினியை ஒழுங்கமைக்க நிராகரிக்கப்பட்ட விண்ணப்பத்தை நீக்குகிறது.
