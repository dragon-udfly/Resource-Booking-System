# Officers Module: பயனர் வழிகாட்டி

## அறிமுகம்
**Officers** மொடியூல் கணினியில் பதிவுசெய்யப்பட்ட அனைத்து அரசு அதிகாரிகளின் அடைவை வழங்குகிறது. தொடர்பு விவரங்களைக் கண்டறியவும் அதிகாரிகளின் பதவிகளைச் சரிபார்க்கவும் இது பயனுள்ளதாக இருக்கும்.

**அணுகல் கட்டுப்பாடு:** இந்தப் பக்கத்திற்கு `view_officers` அனுமதி தேவை.

---

## மொடியூலை அணுகுதல்
1.  கணினியில் **Log in** செய்யவும்.
2.  பிரதான வழிசெலுத்தல் மெனுவில் **Officers** என்பதை கிளிக் செய்யவும்.

---

## அம்சங்கள்

### 1. Officers List
பிரதான அட்டவணை ஒவ்வொரு அதிகாரிக்கான பின்வரும் தகவல்களைக் காட்டுகிறது:
*   **Name:** முழுப் பெயர் (முதல் பெயர் + கடைசி பெயர்).
*   **Designation:** உத்தியோகபூர்வ வேலை தலைப்பு.
*   **Email:** உத்தியோகபூர்வ மின்னஞ்சல் முகவரி.
*   **Contact Number:** பதிவுசெய்யப்பட்ட தொலைபேசி எண்.

### 2. Grade Salary Details
பக்கத்தின் மேலே, ஒரு குறிப்பு அட்டவணை தற்போதைய **Grade Salary Structure**-ஐக் காட்டுகிறது:
*   **Grade:** சேவை தரம் (எ.கா., 1 (G I), 2 (G II)).
*   **Minimum Salary:** அந்த தரத்திற்கான அடிப்படை சம்பளம்.
*   **Maximum Salary:** அந்த தரத்திற்கான அதிகபட்ச சம்பளம்.

*குறிப்பு:* விண்ணப்பங்களில் உள்ள தரவைச் சரிபார்க்க இந்த அட்டவணை ஒரு குறிப்பாகப் பயன்படுகிறது.
