# Preference & Account Settings: User Guide

## அறிமுகம்
**Preference** பக்கமானது உள்நுழைந்த உத்தியோகத்தர்கள் தங்கள் தனிப்பட்ட கணக்கு விவரங்கள் மற்றும் பாதுகாப்பு அமைப்புகளை நிர்வகிக்க அனுமதிக்கிறது. இதில் தொடர்புத் தகவலைப் புதுப்பித்தல் மற்றும் கணினி உள்நுழைவு கடவுச்சொல்லை மாற்றுதல் ஆகியவை அடங்கும்.

---

## பகுதி 1: Preference பக்கத்தை அணுகுதல்
**இணைய முகவரி (URL):** `/preference`

1. **வழிசெலுத்தல்:**
    *   கணினியில் உள்நுழையவும்.
    *   முதன்மை மெனுவில் (மேல் இடது) **Preference** என்பதை கிளிக் செய்யவும்.
    *   *குறிப்பு:* அங்கீகரிக்கப்பட்ட பயனர்களுக்கு மட்டுமே இந்த விருப்பம் பொதுவாகக் கிடைக்கும்.

2.  **இடைமுகக் கண்ணோட்டம்:**
    *   **Top Bar:** "Go Back" மற்றும் "Log Out" பொத்தான்களைக் கொண்டுள்ளது.
    *   **User Info:** உள்நுழைந்த பயனரின் முதல் மற்றும் கடைசி பெயரைக் காட்டுகிறது.
    *   **Profile Details:** மின்னஞ்சல் மற்றும் தொடர்பு எண்ணைப் புதுப்பிப்பதற்கான படிவம்.
    *   **Change Password:** உள்நுழைவு கடவுச்சொல்லைப் புதுப்பிப்பதற்கான படிவம்.

## பகுதி 2: Profile Details -ஐ நிர்வகித்தல்
**படிவப் புலங்கள்:**

1.  **Email Address:**
    *   *திருத்தக்கூடியது:* ஆம்
    *   *கட்டாயமானது:* ஆம்
    *   *விளக்கம்:* கணினி அறிவிப்புகளுக்கான உங்கள் உத்தியோகபூர்வ மின்னஞ்சல் முகவரி.

2.  **Contact Number:**
    *   *திருத்தக்கூடியது:* ஆம்
    *   *கட்டாயமானது:* ஆம்
    *   *விளக்கம்:* உங்கள் முதன்மை தொடர்பு எண் (10 இலக்கங்கள்).

**செயல்முறை:**
1.  தேவைக்கேற்ப **Email Address** அல்லது **Contact Number** புலங்களை மாற்றவும்.
2.  **Update Profile** என்பதை கிளிக் செய்யவும்.
3.  தோன்றும் உறுதிப்படுத்தல் பெட்டியில் செயலை உறுதிப்படுத்தவும் ("Yes, Save Changes").
4.  வெற்றிகரமாக முடிந்ததும், உறுதிப்படுத்தல் செய்தி தோன்றும்.

## பகுதி 3: Password -ஐ மாற்றுதல்
**படிவப் புலங்கள்:**

1.  **New Password:**
    *   *வகை:* Password (இயல்பாக மறைக்கப்பட்டிருக்கும்)
    *   *கட்டாயமானது:* ஆம்
    *   *கட்டுப்பாடுகள்:* குறைந்தது 4 எழுத்துகள்.

2.  **Confirm New Password:**
    *   *வகை:* Password
    *   *கட்டாயமானது:* ஆம்
    *   *கட்டுப்பாடுகள்:* "New Password" உடன் சரியாகப் பொருந்த வேண்டும்.

**செயல்முறை:**
1.  விரும்பிய புதிய கடவுச்சொல்லை உள்ளிடவும்.
2.  **Confirm New Password** புலத்தில் அதே கடவுச்சொல்லை மீண்டும் உள்ளிடவும்.
3.  **Change Password** என்பதை கிளிக் செய்யவும்.
4.  தோன்றும் உறுதிப்படுத்தல் பெட்டியில் செயலை உறுதிப்படுத்தவும்.

## பகுதி 4: Confirmation மற்றும் Processing
இரண்டு செயல்களும் (Profile Update மற்றும் Password Change) பின்வரும் பாதுகாப்பு வழிமுறையைத் தூண்டுகின்றன:

1.  **Confirmation Modal:**
    *   உங்கள் நோக்கத்தை உறுதிப்படுத்த ஒரு உரையாடல் பெட்டி தோன்றும் (எ.கா., *"Are you sure you want to update your profile details?"*).
    *   **Yes, Save Changes:** புதுப்பிப்பைத் தொடரவும்.
    *   **Cancel:** பெட்டியை மூடவும்.

2.  **Processing:**
    *   கணினி உள்ளீட்டைச் சரிபார்க்கிறது (எ.கா., கடவுச்சொல் பொருத்தம், மின்னஞ்சல் வடிவம்).
    *   சேவையகம் கோரிக்கையைக் கையாளும் போது "Processing..." என்ற திரை தோன்றும்.

3.  **Completion:**
    *   **Success:** வெற்றிச் செய்தி காட்டப்படும் (எ.கா., "Profile details updated successfully.").
    *   **Failure:** பிழைச் செய்தி காட்டப்படும் (எ.கா., "Passwords do not match").

---

## பகுதி 5: System Actions & Audit Logging
பாதுகாப்பு மற்றும் பொறுப்புக்கூறலுக்காக கணினி தானாகவே இந்த மாற்றங்களைக் கண்காணிக்கிறது:

1.  **Profile Update:**
    *   தரவுத்தளத்தில் `email` மற்றும் `contact_number` ஆகியவற்றைப் புதுப்பிக்கிறது.
    *   `modified_datetime` நேர முத்திரையைப் புதுப்பிக்கிறது.
    *   **Audit Log:** *"User [ID] updated their profile details"* என்று பதிவு செய்யும்.

2.  **Password Change:**
    *   புதிய கடவுச்சொல்லைச் சேமிப்பதற்கு முன் அதை என்க்ரிப்ட் (hash) செய்கிறது.
    *   `modified_datetime` நேர முத்திரையைப் புதுப்பிக்கிறது.
    *   **Audit Log:** *"User [ID] changed their passcode"* என்று பதிவு செய்யும்.
