# Hall Schedule: பயனர் வழிகாட்டி

## அறிமுகம்
**Hall Schedule** பக்கமானது செயலக மண்டபங்களில் வரவிருக்கும் அனைத்து நிகழ்வுகளின் நிகழ்நேர காலண்டர் மற்றும் பட்டியல் பார்வையை வழங்குகிறது. முன்பதிவு செய்வதற்கு முன் பொதுமக்கள் மற்றும் அதிகாரிகள் மண்டபம் கிடைப்பதை சரிபார்க்க இது அனுமதிக்கிறது.

**URL:** `/hallschedule` (அல்லது முகப்புப்பக்கத்தில் "Halls" இணைப்பு வழியாக)

---

## அம்சங்கள்

### 1. வரவிருக்கும் நிகழ்வுகள் பட்டியல் (Upcoming Events List)
இடது பக்கத்தில், உருட்டக்கூடிய பட்டியல் எதிர்கால முன்பதிவுகளின் விவரங்களைக் காட்டுகிறது:
*   **Programme Name:** நிகழ்வின் தலைப்பு.
    *   *குறிப்பு:* அவசர முன்பதிவுகள் மஞ்சள் உரையுடன் முன்னிலைப்படுத்தப்படுகின்றன.
*   **Hall Type:** எந்த மண்டபம் முன்பதிவு செய்யப்பட்டுள்ளது.
*   **Applicant:** மண்டபத்தை முன்பதிவு செய்தவர்.
*   **Date & Time:** நிகழ்வு கால அளவு.
*   **Status:**
    *   **Approved (பச்சை):** உறுதிப்படுத்தப்பட்ட முன்பதிவு.
    *   **Pending (நீலம்):** ஒப்புதலுக்காக காத்திருக்கிறது (மண்டபம் தற்காலிகமாக தடுக்கப்பட்டுள்ளது).
    *   **Rejected (சிவப்பு):** முன்பதிவு மறுக்கப்பட்டது (இடம் காலியாக உள்ளது).

### 2. நேரடி காலண்டர் (Live Calendar)
ஊடாடும் காலண்டர் முழு மாதத்திற்கான மண்டப ஆக்கிரமிப்பைக் காட்சிப்படுத்துகிறது:
*   **Green Dates:** இந்த நாளில் உறுதிப்படுத்தப்பட்ட (Approved) முன்பதிவுகள் உள்ளன.
*   **Blue Dates:** இந்த நாளில் நிலுவையில் உள்ள (Pending) முன்பதிவுகள் உள்ளன.
*   **White Dates:** முற்றிலும் இலவசம்.
*   **Today:** நீல வட்டத்துடன் முன்னிலைப்படுத்தப்பட்டுள்ளது.

### 3. வழிசெலுத்தல் பொத்தான்கள் (Navigation Buttons)
மேல்-இடது பொத்தான்கள் விரைவான அணுகலை வழங்குகின்றன:
*   **Home:** முகப்புப் பக்கத்திற்குத் திரும்பு.
*   **Halls:** அனைத்து மண்டபங்களின் விரிவான விளக்கத்தைப் பார்க்கவும்.
*   **Book Hall:** முன்பதிவு விண்ணப்பப் படிவத்திற்குச் செல்லவும்.
