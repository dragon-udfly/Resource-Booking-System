# Audit Log Module: User Guide

## Introduction
The **Audit Log** ensures accountability by tracking key actions performed within the system. It provides a transparent record of who did what and when.

**Access Restriction:** This page requires the `view_audit_log` permission.

---

## Accessing the Module
1.  Log in to the system.
2.  Click on **Audit Log** in the main navigation menu.

---

## Features

### Audit Records Table
The system logs events chronologically. The table displays:

*   **Log Title:** A description of the event (e.g., *"User X logged in"*, *"Booking Y approved"*).
*   **Performed By:** The User ID or Name of the person who not performed the action.
*   **Date Performed:** Date of the event (YYYY-MM-DD).
*   **Time Performed:** Time of the event (HH:MM:SS).
