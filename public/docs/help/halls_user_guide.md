# Halls Module: User Guide

## Introduction
The **Halls** module allows users to view details about the available halls within the District Secretariat. This helps in planning events and checking capacity before making a booking.

**Access Restriction:** This page requires the `view_halls` permission.

---

## Accessing the Module
1.  Log in to the system.
2.  Click on **Halls** in the main navigation menu.

---

## Features

### Halls List
The module presents a comprehensive list of halls with the following details:

*   **Hall ID:** Unique identifier for the hall.
*   **Hall Type:** The category of the hall (e.g., Conference Hall, Meeting Room).
*   **Capacity:** Maximum number of people allowed.
*   **Description:** Brief overview of the hall's features.
*   **Hall Status:** Current operational status (e.g., Available, Maintenance).
*   **Special Notice:** Any important alerts or conditions regarding the hall.
