# Halls Overview: User Guide

## Introduction
The **Halls Overview** page serves as a catalog of all available facilities within the District Secretariat. It provides essential information about each hall's features and current operational status.

**URL:** `/halls/overview`

---

## Accessing the Page
*   From the **Hall Schedule** page, click the **"Halls"** button.
*   From the **Homepage**, click content identifying "Halls".

---

## Information Displayed
The table presents a row-by-row breakdown of each facility:

### 1. Hall Type
The specific name or category of the hall (e.g., "Main Conference Hall", "Mini Auditorium").

### 2. Description
A brief summary of the hall's purpose and amenities.

### 3. Current State
Indicates if the hall is ready for booking:
*   **Available:** Ready for immediate booking.
*   **Unavailable/Maintenance:** Currently out of service (Text highlighted in **Red**).

### 4. Special Notice
Any critical alerts regarding the specific hall (e.g., "AC under repair", "Projector unavailable").
