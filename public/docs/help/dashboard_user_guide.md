# User Dashboard & Navigation: User Guide

## Introduction
The **User Dashboard** is the central hub for managing your activities in the Resource Booking System. Its content dynamically changes based on your role (e.g., **Requester** vs. **Approver**). This guide covers the main sections and the navigation bar.

---

## 1. Navigation Bar
The top navigation bar provides quick access to all key areas of the system.

### Key Links
*   **Preference:** (Permission required) Manage account settings and change password.
*   **Dashboard:** Returns to the main user dashboard (your current view).
*   **Officers:** (Permission required) View the list of registered officers.
*   **Halls:** (Permission required) View hall availability and details.
*   **Quarters:** (Permission required) View quarter availability and details.
*   **Homepage:** Go to the public booking portal.
*   **History:** View processed applications (Approved/Rejected/Cancelled).
*   **Audit Log:** (Permission required) View system activity logs.

### User Profile & Logout
*   **Right Side:** Displays your **Designation** and **First Name**.
*   **Log Out:** Securely signs you out of the system.

---

## 2. Dashboard: Overview
Upon logging in, you are greeted with a dashboard tailored to your specific role.

### For Approvers (AO, AGA, GA)
If you hold an administrative role, your dashboard focuses on **Pending Approvals**.

#### A) Pending Booking Approvals (Halls)
*   Displays a table of Hall Booking applications waiting for review.
*   **Columns:** Applicant Name, Submitted Date, and Approval Status for AO, AGA, and GA.
*   **Action:** Click the **Review** button to process an application.

#### B) Quarters Reservation Applications
*   Displays a table of Quarter applications (Scheduled & Family) waiting for verification/allocation.
*   **Columns:** Applicant Name, Designation, Type (Scheduled/Family), and Verification Status (AO, AGA, GA).
*   **Action:** Click the **Review** button to open the detailed review page.

### For Requesters (General Officers)
If you are a standard user, your dashboard tracks **Your Applications**.

#### A) Your Hall Bookings
*   Lists all hall bookings you have submitted that are still **Pending**.
*   Monitor the status of your request as it moves through the approval chain.

#### B) Your Quarter Applications
*   Lists your pending quarter applications.
*   Check if your application has been verified by the AO or AGA.

---

## 3. Key Dashboard Features
*   **Status Indicators:**
    *   **Green:** Approved/Verified.
    *   **Red:** Rejected/Not Verified.
    *   **Gray:** Pending action.
*   **Emergency Bookings:** Rows highlighted in **Yellow** indicate emergency hall bookings requiring immediate attention.
*   **Review Action:** The primary action button takes you to the specific processing page for that item.
