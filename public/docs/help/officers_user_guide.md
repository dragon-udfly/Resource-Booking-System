# Officers Module: User Guide

## Introduction
The **Officers** module provides a directory of all government officers registered in the system. It is useful for finding contact details and verifying officer designations.

**Access Restriction:** This page requires the `view_officers` permission.

---

## Accessing the Module
1.  Log in to the system.
2.  Click on **Officers** in the main navigation menu.

---

## Features

### 1. Officers List
The main table displays the following information for each officer:
*   **Name:** Full Name (First Name + Last Name).
*   **Designation:** Official job title.
*   **Email:** Official email address.
*   **Contact Number:** Registered phone number.

### 2. Grade Salary Details
At the top of the page, a reference table displays the current **Grade Salary Structure**:
*   **Grade:** The service grade (e.g., 1 (G I), 2 (G II)).
*   **Minimum Salary:** The base salary for that grade.
*   **Maximum Salary:** The cap salary for that grade.

*Note:* This table serves as a reference for verifying data in applications.
