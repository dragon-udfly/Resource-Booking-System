# Quarters Module: User Guide

## Introduction
The **Quarters** module provides a detailed inventory of government quarters. It allows authorized users to check vacancy status, capacity, and details of current occupants.

**Access Restriction:** This page requires the `view_quarters` permission.

---

## Accessing the Module
1.  Log in to the system.
2.  Click on **Quarters** in the main navigation menu.

---

## Features

### 1. Occupant Details Button
*   **Action:** Click the green **Occupant Details** button at the top left.
*   **Function:** Navigates to a detailed view of current occupants (if permissions allow).

### 2. Quarters Inventory Table
The table lists all quarters with real-time status:

*   **Identifiction:** Old & New Quarter Numbers.
*   **Location:** Physical address/location.
*   **Type:** Family vs. Individual/Bachelor.
*   **Grade:** Service grade eligibility.
*   **Status:** Current condition (e.g., Good, Repair).
*   **Gender Policy:** Allowed gender for occupants.
*   **Occupancy Stats:**
    *   **Max Occupants:** Total capacity.
    *   **Current Occupants:** Number of people currently living there.
    *   **Vacancies:** Remaining slots available for allocation.
