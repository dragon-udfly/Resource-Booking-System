# History Module: User Guide

## Introduction
The **History** page acts as a centralized archive for all **processed** applications. It allows users to review the final outcome of their requests and download official documentation.

**Access:** All logged-in users.

---

## Accessing the Module
1.  Log in to the system.
2.  Click on **History** in the main navigation menu.

---

## Sections

### 1. Hall Booking Applications
Displays past hall booking requests including:
*   **Applicant Name** & **Event Date**.
*   **Final Approval State:**
    *   **Approved:** (Green) Request was successful.
    *   **Rejected:** (Red) Request was denied.
*   **Reason of Rejection:** Displays the comment if rejected.
*   **Actions:**
    *   **View:** Open full application details.
    *   **Download:** Get a PDF copy of the application/approval.

### 2. Quarters Reservation Applications
Displays past quarter applications (Scheduled & Family) including:
*   **Type:** Scheduled or Family Quarter.
*   **Approval Status:** Allocated, Rejected, or Cancelled.
*   **Actions:**
    *   **View:** Open full application details.
    *   **Download:** Get a PDF copy of the application.

---

## Special Features for Approvers
For **AO, AGA, and GA** roles, the "View" page in History provides additional management controls:

*   **Cancel Allocation:** (GA Only) Revoke an already allocated quarter.
*   **Restore to Pending:** (AO/AGA/GA) Move a rejected application back to the pending queue for re-evaluation.
