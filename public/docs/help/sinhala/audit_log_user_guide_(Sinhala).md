# Audit Log Module: පරිශීලක මාර්ගෝපදේශය

## හැඳින්වීම
**Audit Log** පද්ධතිය තුළ සිදු කෙරෙන ප්‍රධාන ක්‍රියා නිරීක්ෂණය කිරීම මඟින් වගවීම සහතික කරයි. කවුරුන් කුමක් කළේද සහ කවදාද යන්න පිළිබඳ විනිවිද පෙනෙන වාර්තාවක් එය සපයයි.

**ප්‍රවේශ සීමා:** මෙම පිටුවට `view_audit_log` අවසරය අවශ්‍ය වේ.

---

## මොඩියුලයට පිවිසීම
1.  පද්ධතියට **Log in** වන්න.
2.  ප්‍රධාන සංචාලන මෙනුවේ **Audit Log** මත ක්ලික් කරන්න.

---

## විශේෂාංග

### Audit Records Table
පද්ධතිය සිදුවීම් කාලානුක්‍රමිකව ලොග් කරයි. වගුව පහත දෑ පෙන්වයි:

*   **Log Title:** සිදුවීමේ විස්තරය (උදා., *"User X logged in"*, *"Booking Y approved"*).
*   **Performed By:** ක්‍රියාව සිදු කළ පුද්ගලයාගේ පරිශීලක හැඳුනුම්පත (User ID) හෝ නම.
*   **Date Performed:** සිදුවීමේ දිනය (YYYY-MM-DD).
*   **Time Performed:** සිදුවීමේ වේලාව (HH:MM:SS).
