# User Dashboard & Navigation: පරිශීලක මාර්ගෝපදේශය

## හැඳින්වීම
**Dashboard** යනු සම්පත් වෙන්කරවා ගැනීමේ පද්ධතියේ (Resource Booking System) මධ්‍යම පාලන මධ්‍යස්ථානයයි. එහි පිරිසැලසුම සහ අන්තර්ගතය ඔබට පවරා ඇති **Permissions** මත සම්පූර්ණයෙන්ම රඳා පවතී.

*   **පරිපාලන සහ අධීක්ෂණ භූමිකාවන්:** (GA, AGA, AO, Requester) පද්ධතියේ දැනට පවතින සියලුම ඉල්ලුම්පත්වල විස්තීර්ණ පෝලිමක් බලන්න.
*   **සම්මත පරිශීලකයින්:** ප්‍රවේශ අයිතිවාසිකම් මත පදනම්ව සරල කළ හෝ හිස් අතුරු මුහුණතක් බලන්න.

## 1. Navigation Bar
ඉක්මන් ප්‍රවේශය සඳහා සෑම පිටුවකම ඉහළ සංචාලන තීරුව දිස්වේ.

### ප්‍රධාන සබැඳි (Key Links)
*   **Preference:** පුද්ගලික ගිණුම් සැකසීම් කළමනාකරණය කරන්න (Email, Contact, Password).
*   **Dashboard:** මෙම ප්‍රධාන දසුන වෙත ආපසු යයි.
*   **Officers:** (Permission: `view_officers`) ලියාපදිංචි නිලධාරීන්ගේ නාමාවලිය.
*   **Halls:** (Permission: `view_halls`) ශාලා දින දර්ශනය සහ වෙන්කරවා ගැනීමේ විස්තර.
*   **Quarters:** (Permission: `view_quarters`) නිල නිවාස (Quarters) ලබා ගැනීමේ හැකියාව සහ විස්තර.
*   **History:** (Permission: `form_history`) සැකසූ ඉල්ලුම්පත් ලේඛනාගාරය (Approved/rejected).
*   **Audit Log:** (Permission: `view_audit_log`) පද්ධති ක්‍රියාකාරකම් වාර්තා.

### ගිණුම් පාලන (දකුණු පැත්ත)
*   **User Info:** ඔබේ ශ්‍රේණිය/තනතුර සහ නම පෙන්වයි.
*   **Log Out:** ඔබේ සැසිය ආරක්ෂිතව අවසන් කරයි.

## 2. Pending Approvals Dashboard
**ප්‍රේක්ෂකයින්:** `GA Approval`, `AGA Approval`, `AO Approval` හෝ `Requester` අවසර ඇති පරිශීලකයින්.

මෙම උපකරණ පුවරුව **Work Queue** (වැඩ පෝලිමක්) ලෙස ක්‍රියා කරන අතර, පද්ධතිය තුළ ක්‍රියාමාර්ගයක් අපේක්ෂාවෙන් සිටින සියලුම ඉල්ලුම්පත් පෙන්වයි.

### A. Layout & Tools
*   **Fixed Side Menu:** දකුණු පැත්තේ ඇති පාවෙන මෙනුව කොටස් අතර ඉක්මනින් පහළට යාමට (Scroll) ඉඩ දෙයි (Hall, Family, Scheduled).
*   **Banner:** "Pending Booking Approvals" යනුවෙන් පෙන්වයි.

### B. Hall Booking Applications
*   **අන්තර්ගතය:** `Pending` තත්ත්වය සහිත සියලුම ශාලා වෙන්කරවා ගැනීම්.
*   **තීරු:** Applicant Name, Submitted Date, Approval Status (AO/AGA/GA).
*   **ක්‍රියා:**
    *   **Review:** සම්පූර්ණ විස්තර බැලීමට සහ අනුමත කිරීම/ප්‍රතික්ෂේප කිරීම සිදු කිරීමට ක්ලික් කරන්න.
    *   **Emergency:** **කහ** පැහැයෙන් උද්දීපනය කර ඇති පේළි හදිසි ඉල්ලීම් දක්වයි.

### C. Family Quarter Applications
*   **අන්තර්ගතය:** වෙන් කිරීම සඳහා බලා සිටින පවුල් නිල නිවාස ඉල්ලීම්.
*   **වර්ග කිරීම:** **Total Marks** අනුව ස්වයංක්‍රීයව වර්ග කෙරේ (ඉහළම ප්‍රමුඛතාවය ඉහළින්).
*   **තීරු:**
    *   **Applicant:** නම, ශ්‍රේණිය, තනතුර.
    *   **Total Mark:** ජ්‍යෙෂ්ඨත්වය/නිර්ණායක මත පදනම්ව ගණනය කරන ලද ලකුණු.
    *   **Verifications:** AO සහ AGA පියවර සඳහා තත්ත්ව සලකුණු.
*   **ක්‍රියා:** ලේඛන පරීක්ෂා කිරීමට හෝ වෙන් කිරීම අනුමත කිරීමට **Review** ක්ලික් කරන්න.

### D. Scheduled Quarter Applications
*   **අන්තර්ගතය:** වෙන් කිරීම සඳහා බලා සිටින නියමිත නිල නිවාස (Scheduled Quarter) ඉල්ලීම්.
*   **තීරු:** ඉල්ලුම්කරුගේ විස්තර සහ සත්‍යාපන තත්ත්ව දාමය.
*   **ක්‍රියා:** ඉල්ලුම්පත සැකසීමට **Review** ක්ලික් කරන්න.

## 3. Standard User Dashboard
**ප්‍රේක්ෂකයින්:** අනුමත කිරීමේ/ඉල්ලීම් කිරීමේ අවසර නොමැති පරිශීලකයින්.

*   සම්මත පරිශීලකයින් බොහෝ විට විශේෂිත ආකෘති වෙත ප්‍රවේශ වීමට **Navigation Bar** භාවිතා කරනු ඇත (උදා: "Halls" -> "Book Hall").
*   ඔවුන්ගේ මූලික අන්තර්ක්‍රියා මධ්‍යම අනුමත පෝලිමකට වඩා විශේෂිත ක්‍රියාකාරී පිටු (Halls/Quarters) හරහා සිදුවන බැවින් ප්‍රධාන උපකරණ පුවරුව (Dashboard) හිස්ව පැවතිය හැකිය.
