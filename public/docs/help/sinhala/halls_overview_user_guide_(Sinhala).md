## හැඳින්වීම
**Halls Overview** පිටුව දිස්ත්‍රික් ලේකම් කාර්යාලය තුළ පවතින සියලුම පහසුකම් සඳහා හොඳ නාමාවලියක් ලෙස සේවය කරයි. එය එක් එක් ශාලාවේ විශේෂාංග සහ වත්මන් මෙහෙයුම් තත්ත්වය පිළිබඳ අත්‍යවශ්‍ය තොරතුරු සපයයි.

## පෙන්වන තොරතුරු (Information Displayed)
වගුව එක් එක් පහසුකම පේළියෙන් පේළිය බිඳ දමයි:

### 1. Hall Type
ශාලාවේ නම හෝ වර්ගය (උදා., "Main Conference Hall", "Mini Auditorium").

### 2. Description
ශාලාවේ අරමුණ සහ පහසුකම් පිළිබඳ කෙටි සාරාංශයක්.

### 3. Current State
ශාලාව වෙන්කරවා ගැනීමට සූදානම්ද යන්න දක්වයි:
*   **Available:** වහාම වෙන්කරවා ගැනීමට සූදානම්.
*   **Unavailable/Maintenance:** දැනට සේවයෙන් බැහැරව ඇත (පෙළ **රතු** පැහැයෙන් උද්දීපනය කර ඇත).

### 4. Special Notice
විශේෂිත ශාලාව සම්බන්ධයෙන් ඕනෑම විවේචනාත්මක අනතුරු ඇඟවීම් (උදා., "AC under repair", "Projector unavailable").
