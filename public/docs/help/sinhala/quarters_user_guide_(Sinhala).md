# Quarters Module: පරිශීලක මාර්ගෝපදේශය

## හැඳින්වීම
**Quarters** මොඩියුලය රජයේ නිල නිවාස පිළිබඳ සවිස්තරාත්මක ඉන්වෙන්ටරියක් සපයයි. බලයලත් පරිශීලකයින්ට පුරප්පාඩු තත්ත්වය, ධාරිතාව සහ වත්මන් පදිංචිකරුවන්ගේ විස්තර පරීක්ෂා කිරීමට මෙය ඉඩ දෙයි.

**ප්‍රවේශ සීමා:** මෙම පිටුවට `view_quarters` අවසරය අවශ්‍ය වේ.

## විශේෂාංග

### 1. Occupant Details Button
*   **ක්‍රියාව:** ඉහළ වම්පස ඇති කොළ පැහැති **Occupant Details** බොත්තම ක්ලික් කරන්න.
*   **කාර්යය:** වත්මන් පදිංචිකරුවන්ගේ සවිස්තරාත්මක දැක්මකට ගමන් කරයි (අවසර ඉඩ දෙන්නේ නම්).

### 2. Quarters Inventory Table
වගුව තත්‍ය කාලීන තත්ත්වය (real-time status) සහිත සියලුම නිල නිවාස ලැයිස්තුගත කරයි:

*   **Identifiction:** පැරණි සහ නව නිල නිවාස අංක.
*   **Location:** භෞතික ලිපිනය/ස්ථානය.
*   **Type:** Family vs. Individual/Bachelor.
*   **Grade:** සේවා ශ්‍රේණියේ සුදුසුකම්.
*   **Status:** වත්මන් තත්ත්වය (උදා: Good, Repair).
*   **Gender Policy:** පදිංචිකරුවන් සඳහා අවසර ලත් ලිංගභේදය.
*   **Occupancy Stats:**
    *   **Max Occupants:** මුළු ධාරිතාව.
    *   **Current Occupants:** දැනට එහි ජීවත් වන පුද්ගලයින් ගණන.
    *   **Vacancies:** වෙන් කිරීම සඳහා ඉතිරිව ඇති තව් (slots).
